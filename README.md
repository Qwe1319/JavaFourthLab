## Сущности

### Person (Сотрудник)
- **ID** - уникальный идентификатор
- **Имя** - имя сотрудника
- **Пол** - пол (М/Ж)
- **Подразделение** - связь на Department
- **Зарплата** - размер зарплаты
- **Дата рождения** - дата рождения (формат: yyyy-MM-dd)

### Department (Подразделение)
- **ID** - уникальный идентификатор (генерируется автоматически)
- **Название** - название подразделения

CSV файл расположен: `data/people.csv`

Формат CSV:
```
ID;Имя;Пол;Подразделение;Зарплата;Дата рождения
1;Иван Петров;М;IT;75000;1990-05-15
2;Мария Сидорова;Ж;HR;65000;1992-08-22
```

- **Разделитель**: `;` (точка с запятой)
- **Дата**: формат `yyyy-MM-dd`
- **Зарплата**: целые или дробные числа
